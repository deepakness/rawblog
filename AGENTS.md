# AGENTS.md

Eleventy 3 personal site built on rawblog. Two content types, blog posts and raw notes. Use pnpm (Node 22+).

## Commands

- `pnpm start` dev server at http://localhost:8080, drafts visible
- `pnpm run build` production build to `_site/`. Run after any change to content, templates, `_config/`, `_data/`, or scripts. A failed build blocks the change.
- `pnpm ready` optimize images, process videos, generate OG images, sync R2 (skipped when unset)
- `pnpm check` must pass before committing. `pnpm check --strict` also fails on placeholders and sample content.
- `pnpm format` Prettier for JS, CSS, and JSON. Markdown and Nunjucks are not formatted.
- `pnpm blog <slug>` / `pnpm raw <slug>` scaffold `content/{blog,raw}/<slug>/index.md`
- `pnpm blog:push` / `pnpm raw:push` run `ready`, commit, push, announce via CogSend. `:update` skips the announcement. Only run these when asked.
- `pnpm bookmark <url> [--note "…"]`, `pnpm changelog "Title" "Description" [--link label=/path/]`

## Where things live

- `site.config.js` the only place for identity, URL, timezone, nav, socials, and integration settings. Templates read it as `metadata` (`_data/metadata.js`). Scripts and `_config/` import it through `_config/site.js`, which also loads `.env` and exports `SITE_URL`, `SITE_HOST`, `SITE_ZONE`, `ASSET_ORIGIN`. Never hardcode these values elsewhere.
- `.env` secrets (`R2_*`, `ASSET_ORIGIN`, `COGSEND_API_URL`, `COGSEND_API_KEY`), documented in `.env.example`. Empty means the feature is off.
- `content/blog/<slug>/index.md`, `content/raw/<slug>/index.md` entries with co-located media. `blog.11tydata.js` and `raw.11tydata.js` set layouts and must stay.
- `content/*.njk|md` top-level pages. A new page must be added to a list in `_config/wordCountPages.js`.
- `content/feed/` Atom feeds, all rendered by `_includes/atom-feed.njk`.
- `_includes/layouts/` `base.njk` (shell), `home.njk` (pages), `post.njk`, `raw.njk`.
- `_data/*.json` page data (projects, books, bookmarks, blogroll, changelog, gallery). `_data/cache/` is written by scripts, do not edit by hand.
- `_config/filters.js` all filters. `_config/time.js` date parsing in the site timezone (use `toSiteDateTime`, never `new Date()` for display). `_config/drafts.js` the draft rule. `_config/related.js` "Keep reading" scoring.
- `eleventy.config.js` collections, transforms (picture tags, external links, feed media), `{% video %}` shortcode.
- `public/` copied as-is. `public/img/og/` is generated by `pnpm ready`.

## Frontmatter

```yaml
---
title: "Title"
description: "One or two sentences."
date: 2026-11-05 09:30:00.000+00:00
updated: 2026-11-06     # optional
image: /blog/slug/x.png # optional, replaces the generated OG image
affiliate: true         # optional, shows metadata.affiliateNote
draft: true             # optional, excluded from lists, feeds, and production
tags:
- example
---
```

Images use relative paths (`![Alt](./photo.jpg)`). Videos use `{% video "./clip.mp4" %}`. A YouTube URL on its own line becomes an embed.

## Code rules

- Tabs, double quotes, 120 columns. Run `pnpm format` after editing JS, CSS, or JSON.
- Comments explain why, not what.
- New integrations are opt-in. Gate templates on the config value and make scripts exit 0 with a message when unset.
- Changes to scaffolding scripts affect new files only. Do not rewrite existing frontmatter unless asked.

## Writing rules

1. Read at least 10 existing entries before writing, and match their style.
2. Raw notes are a few short paragraphs with no headings. Lists and code blocks are fine.
3. Do not use colons in prose unless a list item needs a label/value pair.
4. Use 2–4 existing tags. Never add a tag unless asked.
5. Add 1–3 internal links (`/blog/<slug>/`, `/raw/<slug>/`) only when genuinely relevant. Link text must not be the target's exact title.
6. Updating an entry: add `updated: YYYY-MM-DD`, append `**Update**: Mon DD, YYYY` at the bottom followed by the new text, and leave the original text unchanged.
7. Link an external source from the first paragraph, not a "Source" line at the end.
8. Never invent first-person claims about the author. Write only what the prompt or provided material supports.
9. Never add affiliate links on your own. Set `affiliate: true` when an entry has them.
10. Cut sentences that carry no fact, instruction, or link.

## Git

Do not commit or push unless asked. Stage only files for the requested change, never `git add .`. Add a `_data/changelog.json` entry (`pnpm changelog`) for visitor-facing site changes, not for posts.
